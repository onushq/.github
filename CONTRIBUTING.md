# Contributing to Onus projects

Thanks for helping. Each repository can have its own guide; when it doesn't, these rules apply.

- Discuss larger changes first, in an issue or in [Discussions](https://github.com/onushq/onus/discussions).
- Keep pull requests focused, with tests where it makes sense.
- Sign off every commit (`git commit -s`) to certify the [Developer Certificate of Origin](https://developercertificate.org/). There is no separate contributor license agreement.
- Contributions are licensed under the repository's license (Apache-2.0 unless it says otherwise).
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

The main project's full guide is [onushq/onus/CONTRIBUTING.md](https://github.com/onushq/onus/blob/main/CONTRIBUTING.md).
