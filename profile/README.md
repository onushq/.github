## Onus

**Code is not the product.** Agents now write code faster than anyone can read it. Onus is the layer every coding agent works through: it reads each change for what it means, routes it by risk, and approves it on evidence instead of on someone pretending to review 2,000 lines.

- **[onus](https://github.com/onushq/onus)**: the engine and the `onus` CLI, written in Rust. Pre-alpha; the plan is public and Phase 1 (semantic change reports on pull requests) comes first.
- **Website:** [onushq.com](https://onushq.com)

Onus is open source under the Apache License 2.0. Questions and ideas are welcome in [Discussions](https://github.com/onushq/onus/discussions).
